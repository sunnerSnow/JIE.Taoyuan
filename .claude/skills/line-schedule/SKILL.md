# 整理行程預告

`web/src/data/schedule.ts` 是 `/trail` 最上面「下一站行程預告」和一天一張分享圖（`/trail/schedule/日期`）的資料。來源有兩種：

- **LINE 官方帳號（@589cjotf）**：用聊天推播公告行程，沒有公開網址、網站外也讀不到，只能由使用者貼上原文或截圖。來源寫 `{ outlet: "LINE 官方帳號公告" }`。
- **官方 Threads 的行程預告貼文**：寫明日期、時間、地點的才收（例如車隊掃街的時段與路線）；只寫「明早見」這類沒有時間地點的不收。用 `tools/official-watch` 的 `npm run read -- <網址>` 讀全文，附圖用 Playwright 下載原圖來讀。來源寫 `{ outlet: "Threads 貼文", url }`。

## 步驟

1. **讀公告**：每場要有時間、活動、地點。截圖或附圖看不清楚的字要問使用者，不要猜。
   完成條件：每場都有時間、活動、地點，字句和公告逐字相同。
2. **更新資料**：每個日期一筆 `ScheduleDay`，新的日期放最前面。同一天已經有資料時，以最新的公告為準整天換掉（行程可能改時間或取消）；兩種來源各公告了不同場次，就依時間合併，`sources` 兩個都列。過去的日子留著。
   完成條件：公告裡的每個日期都在 `schedule.ts`，場次依時間排序，`sources` 列出用到的每個來源。
3. **驗證**：在 `web/` 跑 `npx eslint`、`npx next build`、`npx tsc --noEmit`。用 `npx next start -p 3351` 打開 `/trail/schedule/<日期>` 看圖卡：字沒有壓到頁尾、場次多時整份清單會縮小。再看 `/trail` 的預告區塊（只顯示今天以後的日子）。結束後關掉 3351。
4. **回報與 commit**：貼出繁體中文 commit 訊息（不加 Co-Authored-By），使用者同意後才走 `/review-gate`、commit、push。

## 整理規則

- **照原文**：`title` 是「活動」，`place` 是「地點」括號前的部分，`address` 是括號裡的地址（沒有就不填），全形標點、數字照抄，不補公告沒有的字。`time` 寫 24 小時制 `HH:MM`；公告有寫結束時間才填 `end`。公告沒寫時間時不要自己猜，先問使用者；真的要用別的貼文推得的時間，要在資料旁註明怎麼來的，並在回報時說明。
- **車隊掃街**：`place`、`address` 寫起點；終點和起點不同時寫在 `finish`（例如「蘆竹德林寺（龍安街二段985號）」），相同就不填。`route` 照公告順序列出經過的路段與打氣站，不含起點、終點。
- **車掃路線圖**：新增或修改 `route` 後，在 repo 根目錄跑 `python tools/route-map/build.py`（從 OpenStreetMap 下載路網，重新產生 `web/src/data/route-maps.ts`），路線圖卡在 `/trail/schedule/<日期>/route/<時間去冒號>`。工具回報「找不到路名」或「沒有交會的路口」時，到 `build.py` 的 `ALIASES`（公告路名和 OSM 不同）或 `EXTENSIONS`（同一條路在 OSM 分成不同路名）補對照；新的起點、終點要在 `PLACES` 補座標（OSM 的地址點或建物）。加油打氣站查得到官方地址（例如議員服務處，以市議會議員介紹頁為準）才寫進 `STATIONS` 並註明出處，查不到的只留在路線清單；看圖認路的地標在 `LANDMARKS`。工具會逐條印出「※」警告（OSM 找不到的小巷、兩條路沒相交改走一般道路、路在 OSM 斷成幾段），每條都要看；候選人有貼官方路線圖時拿來對照。路線裡不是路名的點（打氣站、競總、火車站、宮廟）只列在清單裡。打開圖卡確認：號碼照路線順序、路線大致和官方路線圖一致、標籤沒有疊在一起。
- **線上節目**：`place` 寫平台（例如「YouTube 直播」），`url` 放貼文附的觀看網址（Threads 的連結要還原成原始網址，不要用 l.threads.com 轉址）。
- **只收行程本身**：聯絡電話、報名連結、呼籲文字不收。
- **預告不是紀錄**：行程結束後，等官方貼文或媒體報導再用 `/sync-official` 收進 `trail.ts`；LINE 公告不能當 `trail.ts` 的來源（Threads 的預告貼文可以，和當天貼文合成一筆）。
- **格式**：不要對既有檔案跑 prettier，原始碼一行大約 160 字寬。
